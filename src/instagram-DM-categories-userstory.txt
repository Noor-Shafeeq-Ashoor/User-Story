                                           Instagram DM Categories
----------------------------------------------------------------------------------------------------------------------
Allow Instagram users to organize their direct messages into different categories, such as Friends, Family, and Work,
to make conversations easier to manage and find.
----------------------------------------------------------------------------------------------------------------------

User Story 1: Create a Category

As an Instagram user, I want to create a new message category so that I can organize my
conversations based on my needs.

### Acceptance Criteria

1- Given that I am viewing my direct messages, whenI select "Create Category", then I should be able to enter a
category name.
2- Given that I am creating a category, when I choose a "theme", then I should be able to select a theme for that
    category.
3- Given that I have entered a category name, when I confirm the creation, then the new category should appear in my
   message categories.


----------------------------------------------------------------------------------------------------------------------

User Story 2: Add a Conversation to a Category

As an Instagram user, I want to add a conversation to a category so that I can keep my messages organized.

### Acceptance Criteria

1- Given that I have an existing conversation, when I select "Add to Category", then I should be able to choose an
 existing category.
2- - Given that I have added a conversation to a category, when the category is assigned, then the conversation's
 theme should change according to the category.
3- Given that a conversation is already assigned to a category, when I try to add it to the same category again,
 then Instagram should not create a duplicate conversation.


----------------------------------------------------------------------------------------------------------------------

User Story 3: Move a Conversation to Another Category

As an Instagram user, I want to move a conversation from one category to another so that I can keep my categories up
 to date.

### Acceptance Criteria

1- Given that a conversation is already assigned to a category, when I select "Move to Category", then I should be
able to choose another category.
2- Given that I select another category, when I confirm the change, then the conversation should appear in
 the new category and should no longer appear in the previous category.

----------------------------------------------------------------------------------------------------------------------

User Story 4: Rename a Category

As an Instagram user, I want to rename a category so that I can keep the category name relevant to my conversations.

### Acceptance Criteria

1- Given that I have an existing category, when I select "Rename Category", then I should be able to enter a new name.
2- Given that I have entered a new name, when I confirm the change, then the category should display the new name.
3- Given that another category already has the same name, when I try to rename a category using that name, then I
 should not be allowed to use the same name twice.

----------------------------------------------------------------------------------------------------------------------

## User Story 5: Delete a Category

As an Instagram user, I want to delete a category so that I can remove categories that I no longer need.

### Acceptance Criteria

1- Given that I have an existing category, when I select "Delete Category", then I should be asked to confirm
the deletion.
2- Given that I confirm the deletion, when the category is deleted, then it should no longer appear in my message
 categories.
3- Given that the deleted category contains conversations, when the category is deleted, then the conversations should
 remain in my direct messages.
